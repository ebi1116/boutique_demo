AARNA BOUTIQUE - Static website (demo)

HOW TO USE
1. Open index.html in any browser.
2. Edit index.html to change:
   - Shop name: search "Aarna"
   - WhatsApp number: search 919800000000 (91 + 10-digit number)
   - Address / phone / hours: "Visit the boutique" section
   - Products and prices: "var products" list in the script at the bottom
   - Offer code and top bar text: search FESTIVE15
3. Add product photos in the images/ folder (see images/README.txt).

HOSTING
Static site, no backend. Upload the folder to Netlify, Vercel,
GitHub Pages, AWS S3 + CloudFront or any shared hosting.
